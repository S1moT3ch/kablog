# Cartella Foto per Antonio & Katia - KaBlog (25 Anni) 📸

Inserisci qui le tue foto per sostituire quelle attuali!

### Come organizzare e collegare le foto:
1. Copia i tuoi file immagine in questa cartella (es. `foto1.jpg`, `nozze_2001.jpg`, `antonio_lavoro.jpg`, `spesa_sabato.jpg`).
2. Apri il file [`src/data/blogData.js`](file:///d:/Simone/WebApps/kablog/src/data/blogData.js).
3. Sostituisci i link `url: "https://images.unsplash..."` con il percorso locale, ad esempio:
   ```javascript
   url: "/photos/foto1.jpg"
   ```
4. Salva il file: la pagina si aggiornerà istantaneamente senza dover riavviare!
