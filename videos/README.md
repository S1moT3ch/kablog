# Cartella Video MP4 per KaBlog 🎬

Inserisci qui i tuoi file video `.mp4` corrispondenti a ciascun Metodo/Sezione.
Lo script Python (`scripts/play_video.py`) cercherà automaticamente i file con questi nomi:

| Sezione / Metodo | Nome File Richiesto | Descrizione |
| :--- | :--- | :--- |
| **Metodo 1** | `commercialista.mp4` | Antonio H24: Il lavoro da commercialista |
| **Metodo 2** | `matematica_faidate.mp4` | Katia & La Matematica vs Fai-da-te di Antonio |
| **Metodo 3** | `casa_figli.mp4` | La Cura della Casa & I Figli (Simone e Andrea) |
| **Metodo 4** | `spesa_sabato.mp4` | Il Rito del Sabato: Spedizione al Supermercato |
| **Metodo 5** | `ierieoggi.mp4` | Quel 26 Settembre 2001 vs Oggi (25 Anni Insieme) |

---

### Note di Riproduzione con VLC:
- I video verranno aperti automaticamente a **schermo intero** (`--fullscreen`).
- Al termine della riproduzione, VLC si chiuderà da solo (`--play-and-exit`), tornando subito alla schermata della guida.
- Se un file video non è ancora presente, lo script mostrerà un avviso amichevole indicando quale file manca.
